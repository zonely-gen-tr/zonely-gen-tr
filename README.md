## What We Build

Zonely connects websites, stores, game servers, payment flows, license systems, and mobile experiences into a single product ecosystem. The projects here are organized around one goal: helping communities and digital businesses run their operations from a cleaner, more connected stack.

## Main Projects

| Project | Purpose |
| --- | --- |
| [Zonely](https://github.com/zonely-gen-tr/Zonely) | Main platform for digital marketing, domain management, and multi-channel operations. |
| [ZonelyCore](https://github.com/zonely-gen-tr/ZonelyCore) | Game-side core for auth, stores, auctions, reports, leaderboards, and website sync. |
| [ZonelyMobile](https://github.com/zonely-gen-tr/ZonelyMobile) | Mobile APK/iOS delivery flow for Zonely-powered panels and websites. |
| [ZonelyPay](https://github.com/zonely-gen-tr/ZonelyPay) | Payment integration layer for Zonely products and services. |
| [ZonelyPartner](https://github.com/zonely-gen-tr/ZonelyPartner) | Partner, reseller, platform administration, and license management tooling. |
