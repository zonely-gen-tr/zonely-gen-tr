## Zonely Projects

- [**Zonely**](https://github.com/zonely-gen-tr/Zonely) - Main platform for digital marketing, domain management, multi-channel operations, and website-based commerce.
- [**ZonelyCore**](https://github.com/zonely-gen-tr/ZonelyCore) - Game-side core powering auth, stores, auctions, reports, leaderboards, and website sync. ZonelyCore provides:
  - Website-to-server command flow
  - Store, auction, auth, and leaderboard integrations
  - Server-side extensions for connected communities
- [**ZonelyMobile**](https://github.com/zonely-gen-tr/ZonelyMobile) - Android APK and iOS delivery flow for Zonely-powered panels and websites.
- [**ZonelyPay**](https://github.com/zonely-gen-tr/ZonelyPay) - Payment integration layer for Zonely products and services.
- [**ZonelyPartner**](https://github.com/zonely-gen-tr/ZonelyPartner) - Partner, reseller, platform administration, and license management tools.
